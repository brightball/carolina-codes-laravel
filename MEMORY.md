# Memory

Durable knowledge for this API is committed Markdown. Keep this index short. Do not add an embedding store, a Laravel Boost `.ai/rules` tree, or notes that live only outside git.

| Read when | File |
|---|---|
| You need the polyglot contract or how this process is served | [AGENTS.md](AGENTS.md) |
| You need why a choice was made, or you are about to change one | [DECISIONS.md](DECISIONS.md) |

Update `DECISIONS.md` in the same commit when a durable decision changes. Leave secrets, tokens, and private hostnames out of both files.
